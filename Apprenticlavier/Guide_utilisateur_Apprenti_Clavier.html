1. Présentation

Apprenti Clavier est une application macOS conçue pour apprendre progressivement la frappe au clavier. Elle est entièrement utilisable avec VoiceOver et s’adresse aux personnes voyantes, malvoyantes et aveugles. Dans l’espace Apprenant, chacun peut suivre les 14 modules intégrés à l’application. Il peut également suivre les leçons personnalisées qu’un formateur lui a attribuées. La progression est enregistrée automatiquement pour chaque profil apprenant.

À noter : les commandes VoiceOver indiquées dans ce guide pour atteindre les en-têtes, parcourir les éléments ou interagir avec une zone présentent une manière d’effectuer ces actions. Vous pouvez utiliser une autre méthode VoiceOver si elle vous permet d’obtenir le même résultat.

2. Installation de l’application

Configuration requise

Apprenti Clavier nécessite macOS Monterey 12.0 ou une version ultérieure. L’application est prévue pour les Mac Intel et Apple Silicon.

Installer l’application

Ouvrez le fichier « Apprenti Clavier.dmg », puis copiez l’application dans le dossier Applications.

Autoriser la première ouverture

Lors de la première ouverture, macOS peut empêcher le lancement de l’application et afficher un message indiquant qu’elle provient d’un développeur non identifié. Après avoir essayé une première fois d’ouvrir Apprenti Clavier, effectuez l’une des procédures suivantes selon votre version de macOS.

Sur les versions récentes de macOS

  • Ouvrez le menu Pomme, puis Réglages Système.
  • Sélectionnez Confidentialité et sécurité.
  • Faites défiler la fenêtre jusqu’à la rubrique Sécurité.
  • Un message indique qu’Apprenti Clavier a été bloqué afin de protéger votre Mac.
  • Cliquez sur le bouton « Ouvrir quand même ».
  • Dans la nouvelle fenêtre d’avertissement, cliquez sur le bouton « Ouvrir ».
  • Si nécessaire, saisissez votre mot de passe d’ouverture de session ou utilisez Touch ID.

Sur les anciennes versions de macOS

  • Ouvrez le menu Pomme, puis Préférences Système.
  • Sélectionnez Sécurité et confidentialité, puis l’onglet Général.
  • Dans la partie inférieure de la fenêtre, un message indique qu’Apprenti Clavier a été bloqué, car l’application ne provient pas d’un développeur identifié.
  • Cliquez sur le bouton « Ouvrir quand même ».
  • Confirmez ensuite l’ouverture de l’application.
  • Si nécessaire, saisissez votre mot de passe d’ouverture de session.

Une fois cette autorisation accordée, Apprenti Clavier pourra être ouvert normalement lors des utilisations suivantes.

Vérifier et installer les mises à jour

Si aucun choix n’a encore été effectué concernant la recherche automatique des mises à jour, une boîte de dialogue s’affiche à l’ouverture d’Apprenti Clavier. Elle vous demande si vous souhaitez activer cette recherche automatique.

Une case permet également d’autoriser le téléchargement et l’installation automatiques des mises à jour. Selon votre choix, cliquez ensuite sur le bouton « Vérifier automatiquement » ou « Ne pas vérifier ».

Apprenti Clavier peut ainsi rechercher automatiquement les nouvelles versions disponibles. Vous pouvez également effectuer une vérification manuelle à tout moment en ouvrant le menu Apprenti Clavier, puis en sélectionnant « Rechercher les mises à jour… ».

Lorsqu’une nouvelle version est disponible, l’application vous l’indique. Cliquez sur le bouton « Installer » pour lancer la mise à jour. Le téléchargement et l’installation sont effectués directement depuis Apprenti Clavier.

Lorsque l’installation est terminée, l’application se ferme puis se relance automatiquement. Vous utilisez alors la nouvelle version d’Apprenti Clavier. Vos profils, vos leçons personnalisées et votre progression sont conservés.

En cas de problème

Si la mise à jour ne peut pas être installée depuis l’application, vous pouvez télécharger le fichier DMG de la dernière version depuis la page GitHub d’Apprenti Clavier, puis effectuer une installation manuelle.

Le lien vers cette page GitHub est disponible dans la fenêtre « À propos d’Apprenti Clavier », accessible depuis le menu Apprenti Clavier.

3. Premier lancement

Au premier démarrage, l’accueil présente deux espaces : « Espace apprenant » et « Espace formateur ». Pour commencer votre apprentissage, rejoignez l’Espace apprenant, puis créez votre profil.

Navigation avec VoiceOver dans l’écran d’accueil

Les en-têtes suivants sont disponibles :

  • « Apprenti Clavier »
  • « Accueil »
  • « Espace apprenant »
  • « Choisissez un apprenant », lorsqu’un profil apprenant existe déjà
  • « Créer un apprenant »
  • « Espace formateur »
  • « Choisissez un formateur », lorsqu’un profil formateur existe déjà
  • « Créer un formateur »

Utilisation du rotor VoiceOver

Dans le rotor VoiceOver, sélectionnez « En-têtes Apprenti Clavier » pour parcourir directement les différents en-têtes de l’écran d’accueil.

Créer votre profil apprenant

Dans la section « Créer un apprenant », cliquez dans le champ de saisie du nom, saisissez votre nom, puis appuyez sur Entrée.

Avec VoiceOver

  • Utilisez plusieurs fois VO + Commande + H jusqu’à atteindre l’en-tête « Créer un apprenant ».
  • Si vous avez dépassé cet en-tête, utilisez VO + Commande + Majuscule + H pour revenir à l’en-tête précédent.
  • Utilisez ensuite VO + Flèche droite jusqu’au champ de saisie du nom d’apprenant.
  • Saisissez votre nom, puis appuyez sur Entrée.
  • Votre profil apprenant est créé, l’Espace apprenant s’ouvre et VoiceOver place le focus sur le titre « Bonjour [nom] ».

4. Découverte de l’interface

Après la création ou la sélection de votre profil, l’Espace apprenant s’ouvre. Lors de la première ouverture et à chaque nouvelle connexion à ce profil, VoiceOver place le focus sur le titre « Bonjour, [nom de l’apprenant] ! ».

Après l’en-tête « Espace apprenant », un message indique le nombre de leçons terminées par l’apprenant.

Boutons de l’Espace apprenant

  • Reprendre ma progression : ouvre la prochaine leçon intégrée à effectuer selon votre progression.
  • Choisir un module : ouvre la liste des 14 modules intégrés et de leurs leçons.
  • Leçons personnalisées : ouvre la liste des leçons qui vous ont été attribuées par un formateur. Ce bouton apparaît uniquement lorsqu’au moins une leçon personnalisée est disponible pour votre profil.
  • Statistiques : ouvre la fenêtre « Mes statistiques » du profil actif.
  • Changer d’apprenant : affiche l’accueil dans la fenêtre principale afin de sélectionner ou de créer un autre profil apprenant.
  • Réglages : ouvre les réglages de l’application.

Avec VoiceOver

Parcourez les boutons avec VO + Flèche gauche et VO + Flèche droite, puis activez-les avec VO + Espace.

Lorsque vous revenez des modules, des leçons personnalisées ou des réglages, VoiceOver place de nouveau le focus sur l’en-tête « Espace apprenant ».

Mode plein écran

Apprenti Clavier peut être utilisé aussi bien en mode fenêtre qu’en mode plein écran. Pour activer ou quitter le mode plein écran :

  • Ouvrez le menu Présentation puis choisissez « Activer le mode plein écran » ou « Quitter le mode plein écran », selon l’état actuel de la fenêtre.
  • Le raccourci clavier correspondant est affiché directement dans ce menu.
  • Vous pouvez également utiliser le bouton Plein écran situé dans l’angle supérieur gauche de la fenêtre.

Revenir en arrière et fermer une fenêtre

La touche Échap permet de revenir à l’écran précédent :

  • depuis l’intérieur d’un module, elle revient à la liste des modules ;
  • depuis la liste des modules, elle revient à l’Espace apprenant ;
  • depuis la fenêtre affichant la liste des leçons personnalisées, elle revient à l’Espace apprenant ;
  • depuis les réglages, elle ferme les réglages et revient à la fenêtre qui était affichée avant leur ouverture.

La touche Échap permet également de fermer les fenêtres secondaires d’Apprenti Clavier, notamment « Mes statistiques », « À propos d’Apprenti Clavier » et le « Centre d’aide ».

Vous pouvez également fermer la fenêtre active avec le raccourci Commande + W ou avec son bouton de fermeture habituel.

5. Gestion des profils apprenants

Les profils apprenants permettent à plusieurs personnes d’utiliser Apprenti Clavier sur le même Mac tout en conservant une progression indépendante. Chaque profil enregistre notamment :

  • la progression dans les modules et les leçons intégrées ;
  • les statistiques d’apprentissage ;
  • les statistiques concernant les erreurs et la vitesse de frappe.

À savoir

Les leçons personnalisées attribuées par un formateur sont accessibles uniquement depuis le profil de l’apprenant concerné.

Les réglages de l’application sont communs à tous les profils et ne sont pas enregistrés séparément pour chaque apprenant.

Créer un profil apprenant

La création du premier profil est expliquée dans le chapitre « Premier lancement ».

Pour créer un autre profil apprenant :

  • Dans l’Espace apprenant, cliquez sur le bouton « Changer d’apprenant ». Vous pouvez également choisir « Changer d’apprenant… » dans le menu « Apprenant ».
  • Dans l’accueil, dans la section « Créer un apprenant », cliquez dans le champ de saisie, saisissez le nom du nouvel apprenant, puis appuyez sur Entrée.
  • Le nouveau profil est créé et devient automatiquement le profil actif.

Avec VoiceOver

  • Quelle que soit la méthode utilisée pour changer d’apprenant, l’accueil s’affiche et le focus se place automatiquement sur l’en-tête « Espace apprenant ».
  • Rejoignez l’en-tête « Créer un apprenant », puis utilisez VO + Flèche droite jusqu’au champ de saisie.
  • Saisissez le nom du nouvel apprenant, puis appuyez sur Entrée.
  • Après la création, VoiceOver place le focus sur le titre « Bonjour, [nom de l’apprenant] ! ».

Sélectionner un profil apprenant existant

À chaque nouveau lancement de l’application, l’accueil s’affiche dans la fenêtre principale afin que chaque personne sélectionne explicitement son profil apprenant.

Lorsque vous utilisez le bouton « Changer d’apprenant » ou la commande « Changer d’apprenant… » du menu « Apprenant », VoiceOver place automatiquement le focus sur l’en-tête « Espace apprenant ».

Pour sélectionner un profil existant :

Dans la section « Choisissez un apprenant », cliquez sur « Continuer avec [nom de l’apprenant] » correspondant au profil souhaité. L’Espace apprenant s’ouvre avec ce profil.

Avec VoiceOver

  • Rejoignez l’en-tête « Choisissez un apprenant ».
  • Utilisez VO + Flèche droite jusqu’au bouton « Continuer avec [nom de l’apprenant] » correspondant au profil souhaité, puis activez-le avec VO + Espace.
  • VoiceOver place le focus sur le titre « Bonjour, [nom de l’apprenant] ! ».

Utiliser plusieurs profils apprenants

Apprenti Clavier peut gérer plusieurs profils apprenants sur le même Mac. Cette fonctionnalité est particulièrement utile lorsque l’ordinateur est partagé entre plusieurs membres d’une famille, dans un établissement scolaire ou dans une association.

Progression indépendante

Chaque profil apprenant possède sa propre progression et ses propres statistiques. Lorsqu’un apprenant termine une leçon ou un module, cette progression est enregistrée uniquement dans son profil. Les autres apprenants conservent leur propre avancement et peuvent donc se trouver à des niveaux différents.

Supprimer le profil apprenant actif

La suppression concerne uniquement le profil apprenant actuellement connecté.

Pour supprimer votre profil apprenant, commencez par ouvrir les réglages. Trois méthodes sont possibles :

  • cliquez sur le bouton « Réglages » présent dans l’Espace apprenant ;
  • choisissez « Réglages… » dans le menu « Apprenti Clavier » ;
  • utilisez le raccourci Commande + Virgule.

Une fois la fenêtre des réglages affichée :

  • Dans la section « Suppression du profil de [nom de l’apprenant] », cliquez sur « Supprimer ce profil… ».
  • Dans la demande « Supprimer ce profil ? », cliquez sur « Supprimer » pour confirmer ou sur « Annuler » pour conserver le profil.

À noter : si vous confirmez la suppression, le profil, sa progression et ses statistiques seront définitivement supprimés.

Avec VoiceOver : rejoignez l’en-tête « Suppression du profil de [nom de l’apprenant] », puis parcourez les commandes jusqu’au bouton « Supprimer ce profil… » et activez-le avec VO + Espace. Après confirmation, VoiceOver place le focus sur le message « Le profil [nom de l’apprenant] a été supprimé. ».

Conseil : avant de supprimer un profil apprenant, il est recommandé de l’exporter avec la commande « Exporter mon profil… » du menu « Fichier ». Vous conserverez ainsi une sauvegarde au format JSON, qui pourra être réimportée ultérieurement.

6. Importer et exporter un profil apprenant

Importer un profil apprenant

Pour importer un profil apprenant, ouvrez le menu « Fichier », puis choisissez « Importer un profil… ». Dans la fenêtre intitulée « Importer un profil », sélectionnez le fichier JSON correspondant au profil que vous souhaitez importer, puis cliquez sur le bouton « Importer ».

Après l’importation, un bouton « Continuer avec [nom de l’apprenant] » apparaît sur la page d’accueil, dans la liste des profils existants de la section « Choisissez un apprenant ». Cliquez sur ce bouton pour ouvrir le profil importé.

Avec VoiceOver

  • Après avoir sélectionné le fichier, utilisez VO + Flèche droite jusqu’au bouton « Importer ».
  • Activez ce bouton avec VO + Espace.
  • Une boîte de dialogue intitulée « Profil importé » confirme que le profil a bien été importé.
  • Appuyez sur Entrée pour fermer cette fenêtre.
  • Rejoignez le bouton « Continuer avec [nom de l’apprenant] », puis activez-le avec VO + Espace pour ouvrir le profil importé.

Si un profil portant le même nom existe déjà, le profil importé est automatiquement renommé, par exemple « Aurélien importé 2 », afin de ne pas remplacer le profil existant.

Exporter un profil apprenant

Pour exporter un profil, celui-ci doit être actif. Dans le menu « Fichier », choisissez « Exporter mon profil… ».

Une sauvegarde au format JSON est enregistrée dans le dossier Téléchargements. Le Finder s’ouvre automatiquement et sélectionne le fichier créé.

Une boîte de dialogue intitulée « Profil exporté » confirme la réussite de l’exportation. Appuyez sur Entrée pour fermer cette fenêtre.

À savoir

Il est recommandé d’exporter régulièrement les profils apprenants importants afin de conserver une sauvegarde récente de leur progression. Si un fichier portant le même nom existe déjà, l’application crée un nouveau fichier sans remplacer la sauvegarde précédente.

7. Modules et leçons

L’apprentissage est organisé en modules composés de plusieurs leçons. Chaque leçon débute par une ou plusieurs fiches pédagogiques avant de proposer des exercices pratiques. Une leçon de consolidation permet de réviser les notions abordées. Les 14 modules vous accompagnent étape par étape, de la découverte des rangées du clavier jusqu’à la saisie de phrases complètes.

Les 14 modules

  • Module 1 : Découverte du clavier
  • Module 2 : Barre d’espace et rangée supérieure
  • Module 3 : Rangée inférieure
  • Module 4 : Consolidation des trois rangées
  • Module 5 : Les mots courts
  • Module 6 : Les mots longs
  • Module 7 : Les mots enchaînés
  • Module 8 : Les majuscules
  • Module 9 : Les mots avec une majuscule
  • Module 10 : Les mots enchaînés : majuscules et espaces
  • Module 11 : Les lettres accentuées
  • Module 12 : Les mots accentués
  • Module 13 : La ponctuation
  • Module 14 : Les phrases

Accéder aux modules

Dans l’écran principal de l’Espace apprenant, cliquez sur le bouton « Choisir un module ». Dans la fenêtre « Modules », cliquez sur le module que vous souhaitez ouvrir.

Avec VoiceOver : activez « Choisir un module » avec VO + Espace. Le focus se place sur l’en-tête « Modules ». Les 14 modules sont présentés comme des en-têtes et des boutons. Naviguez par en-tête jusqu’au module souhaité, puis ouvrez-le avec VO + Espace.

Mémorisation progressive

Dans les premiers exercices consacrés à de nouvelles touches, les indications rappellent le placement des doigts et les déplacements à effectuer. Ces indications sont ensuite progressivement allégées afin de favoriser la mémorisation des gestes et de permettre à l’apprenant de retrouver naturellement la position des touches.

Leçons personnalisées

Lorsque des leçons personnalisées vous ont été attribuées par un formateur, le bouton « Leçons personnalisées » apparaît dans l’écran principal de l’Espace apprenant. Cliquez sur ce bouton pour afficher les leçons qui vous sont proposées.

Avec VoiceOver

Placez-vous sur le bouton « Leçons personnalisées », puis activez-le avec VO + Espace. À l’ouverture, le focus se place sur l’en-tête « Leçons personnalisées ». Les leçons sont regroupées par formateur. Chaque groupe possède un en-tête indiquant le nom du formateur et le nombre de leçons proposées, par exemple « Marie — 2 leçons ».

Vous pouvez naviguer par en-tête pour passer rapidement d’un formateur à un autre. Une fois le formateur souhaité atteint, utilisez VO + Flèche droite pour parcourir ses leçons, puis VO + Espace pour commencer celle de votre choix.

À savoir

Prenez le temps de placer correctement vos doigts avant de commencer les exercices. Une bonne position facilite la mémorisation des touches et améliore progressivement votre vitesse de frappe.

8. Exercices

Fiches pédagogiques

Les leçons des 14 modules commencent par plusieurs fiches pédagogiques.

Après avoir consulté une fiche, cliquez sur le bouton « J’ai compris » ou appuyez sur la touche Entrée pour passer à la fiche suivante. Depuis la dernière fiche pédagogique, cliquez sur le bouton « Commencer les exercices » ou appuyez sur Entrée.

Avec VoiceOver : vous pouvez attendre la fin de la lecture de chaque fiche avant d’appuyer sur Entrée.

À noter pour les leçons personnalisées

Dans une leçon personnalisée, les fiches pédagogiques sont facultatives. Si le formateur n’en a pas ajouté, la leçon commence directement par les exercices.

Déroulement des exercices

Chaque exercice affiche une consigne ainsi qu’un champ de texte destiné à recevoir votre réponse. Saisissez le texte demandé puis validez avec la touche Entrée.

  • Si votre réponse est correcte, l’exercice suivant s’ouvre automatiquement.
  • En cas d’erreur, le champ de texte est vidé et le curseur est automatiquement placé de nouveau dans celui-ci afin que vous puissiez recommencer immédiatement.

Sons de validation

Lorsque les sons de validation sont activés, un son bref indique que la réponse est correcte et un autre son indique qu’elle est incorrecte. Les sons de validation peuvent être activés ou désactivés depuis les Réglages de l’application.

Annonce automatique du texte restant à taper

Lorsque l’option « Annoncer automatiquement le texte restant à taper » est activée, VoiceOver annonce automatiquement la partie du texte qu’il vous reste à saisir après chaque caractère. Cette option peut être activée ou désactivée depuis les réglages de l’application. La procédure est décrite dans le chapitre « Réglages ».

À la fin de la leçon

À la fin des exercices d’une leçon des 14 modules, un résumé final est automatiquement affiché. Pour le fermer, cliquez sur le bouton « Terminer la leçon » ou appuyez sur la touche Entrée. L’application revient ensuite automatiquement à la fenêtre du module.

À noter pour les leçons personnalisées

Dans une leçon personnalisée, le résumé final est facultatif. Si le formateur en a ajouté un, il apparaît après le dernier exercice. Cliquez alors sur le bouton « Terminer la leçon » ou appuyez sur Entrée.

Si aucun résumé final n’a été ajouté, l’application revient directement à la liste des leçons personnalisées après la réussite du dernier exercice. Dans les deux cas, VoiceOver place de nouveau le focus sur la leçon que vous venez de terminer.

9. Comprendre la progression

Votre progression est enregistrée automatiquement tout au long de votre apprentissage. Dans chacun des 14 modules, les leçons se déverrouillent dans l’ordre pédagogique prévu.

Repérer l’état d’un module ou d’une leçon

Un symbole placé à gauche du nom de chaque module ou de chaque leçon permet de connaître son état :

  • un cadenas rouge indique que le module ou la leçon est verrouillé ;
  • une coche verte indique que le module ou la leçon a été terminé ;
  • l’absence de symbole indique que le module ou la leçon est disponible, mais pas encore terminé.

Lorsqu’une leçon est terminée, la suivante devient automatiquement disponible. Lorsque toutes les leçons d’un module sont terminées, le module suivant est déverrouillé.

Avec VoiceOver : VoiceOver annonce l’état des modules et des leçons verrouillés ou terminés lorsque vous les parcourez. Lorsque vous tentez d’activer un module ou une leçon verrouillé, un son de cadenas est joué, puis VoiceOver vous indique le module ou la leçon à terminer pour le déverrouiller. Pour un élément disponible qui n’a pas encore été terminé, aucun état particulier n’est annoncé.

À savoir

Les modules et les leçons terminés peuvent être recommencés à tout moment sans perdre votre progression. Les leçons personnalisées n’ont aucune incidence sur votre progression dans les 14 modules. Vous pouvez réinitialiser la progression depuis les réglages de l’application ; la procédure est décrite dans le chapitre « Réglages ».

10. Statistiques

La fenêtre « Mes statistiques » permet de consulter les statistiques d’apprentissage du profil actuellement actif. Les informations affichées sont propres à ce profil.

Ouvrir Mes statistiques

Pour consulter les statistiques du profil apprenant actif, ouvrez la fenêtre « Mes statistiques » de l’une des façons suivantes :

  • cliquez sur le bouton « Statistiques » dans l’écran principal de l’Espace apprenant ;
  • dans le menu « Apprenant », choisissez « Mes statistiques ».

Informations disponibles

La fenêtre présente les informations du profil apprenant actif :

  • le nombre total de leçons terminées et le pourcentage de progression générale ;
  • la vitesse moyenne et la meilleure vitesse, exprimées en mots par minute ;
  • le nombre de leçons terminées et le pourcentage de progression dans chacun des 14 modules.

La mesure de la vitesse commence avec les exercices de mots du module 5. Un mot correspond à cinq caractères.

À savoir

Les statistiques sont enregistrées séparément pour chaque profil.

Avec VoiceOver : à l’ouverture, VoiceOver place le focus sur l’en-tête « Mes statistiques ». D’autres en-têtes permettent d’accéder rapidement aux sections « Progression générale », « Vitesse de frappe » et « Progression par module ». Chaque module est également présenté comme un en-tête afin de faciliter la consultation de sa progression.

Utilisation du rotor VoiceOver

Dans le rotor VoiceOver, sélectionnez « En-têtes Apprenti Clavier » pour parcourir les différents en-têtes de la fenêtre. Sélectionnez « Boutons Apprenti Clavier » pour parcourir directement les boutons disponibles.

Exporter mes statistiques

Le bouton « Exporter mes statistiques » permet d’enregistrer les statistiques du profil apprenant actif dans un fichier texte. Le fichier est enregistré dans le dossier Téléchargements, puis automatiquement sélectionné dans le Finder.

Fermer la fenêtre

La fenêtre « Mes statistiques » peut être fermée de plusieurs façons :

  • avec le bouton « Fermer », situé en bas à droite de la fenêtre ;
  • avec la touche Échap ;
  • avec le raccourci standard de macOS Commande + W ;
  • avec le bouton de fermeture habituel de macOS, situé dans l’angle supérieur gauche de la fenêtre.

  • régler le délai des annonces VoiceOver ;

Dans le rotor VoiceOver, sélectionnez « En-têtes Réglages » pour parcourir directement les différentes catégories de la fenêtre.

Apparence

Vous pouvez laisser Apprenti Clavier suivre automatiquement l’apparence de macOS ou choisir une apparence claire ou sombre.

Annonce automatique du texte restant à taper

Lorsque cette option est activée, VoiceOver annonce automatiquement la partie du texte qu’il reste à saisir après chaque caractère tapé. Elle peut être activée ou désactivée à tout moment.

Délai des annonces VoiceOver

Ce réglage permet de choisir le temps d’attente avant l’annonce automatique du texte restant à taper. Cinq valeurs sont proposées :

  • Très rapide : un quart de seconde ;
  • Rapide : une demi-seconde ;
  • Normal : une seconde ;
  • Confortable : une seconde et demie ;
  • Lent : deux secondes.

Lorsque l’annonce automatique du texte restant à taper est désactivée, le réglage du délai devient indisponible, car il n’est alors plus nécessaire.

Sons de validation des exercices

L’option « Sons de validation » permet d’activer ou de désactiver les sons joués pendant les exercices. Lorsqu’elle est activée, un son confirme une bonne réponse et un autre signale une réponse incorrecte. Cette option est activée par défaut.

Les boutons des demandes de confirmation sont entièrement accessibles au clavier. Après une réinitialisation ou une suppression, VoiceOver place automatiquement le focus sur le message confirmant l’opération.

16. Questions fréquentes

Sur quelles versions de macOS Apprenti Clavier peut-il être utilisé ?

Apprenti Clavier nécessite macOS Monterey 12.0 ou une version ultérieure. L’application ne peut pas être utilisée avec une version antérieure de macOS.

Peut-on refaire une leçon déjà terminée ?

Oui. Une leçon terminée reste disponible et peut être recommencée à tout moment, sans perdre votre progression.

Pourquoi des modules ou des leçons sont-ils parfois verrouillés ?

Dans chacun des 14 modules, une leçon reste verrouillée tant que la leçon précédente n’a pas été terminée. Le module suivant reste également verrouillé tant que toutes les leçons du module précédent ne sont pas terminées. Ce fonctionnement permet de respecter la progression pédagogique prévue.

Les profils apprenants sont-ils conservés lors d’une mise à jour de l’application ?

Oui. La mise à jour d’Apprenti Clavier ne supprime pas vos profils apprenants ni leur progression. Par mesure de précaution, il est toutefois recommandé d’exporter votre profil apprenant avant d’installer une nouvelle version.

Comment utiliser mon profil apprenant sur un autre Mac ?

Dans le menu « Fichier », choisissez « Exporter mon profil… », puis copiez le fichier JSON obtenu sur l’autre Mac. Sur cet ordinateur, ouvrez le menu « Fichier » et choisissez « Importer un profil… » pour retrouver votre progression. La procédure complète est décrite dans le chapitre « Importer et exporter un profil apprenant ».

Que se passe-t-il si le nom du profil importé est déjà utilisé ?

Le profil apprenant déjà présent dans l’application n’est ni remplacé ni supprimé. Le profil importé est ajouté à la liste des apprenants sous un nouveau nom. Par exemple, si un profil nommé « Aurélien » existe déjà, le profil importé sera nommé « Aurélien importé 2 ». Si ce nom est également utilisé, le numéro suivant disponible sera automatiquement choisi.

Où consulter mes statistiques ?

Cliquez sur le bouton « Statistiques » dans l’écran principal de l’Espace apprenant ou, dans le menu « Apprenant », choisissez « Mes statistiques ». Les statistiques affichées concernent uniquement le profil apprenant actif.

Comment mettre à jour Apprenti Clavier ?

La recherche, le téléchargement et l’installation des mises à jour s’effectuent directement depuis l’application. Pour plus d’informations, consultez le chapitre « Installation de l’application ».

Peut-on désactiver l’annonce automatique du texte restant à taper ?

Oui. Cette option peut être activée ou désactivée à tout moment depuis les Réglages de l’application. Pour plus d’informations, consultez le chapitre « Réglages ».

Pourquoi le bouton « Leçons personnalisées » n’apparaît-il pas ?

Le bouton « Leçons personnalisées » apparaît dans l’écran principal de l’Espace apprenant uniquement lorsqu’un formateur a attribué au moins une leçon personnalisée au profil apprenant actif.

Pourquoi VoiceOver annonce-t-il parfois une zone de défilement ?

Certaines fenêtres de l’application utilisent une zone de défilement lorsque leur contenu dépasse la taille de la fenêtre. Ce fonctionnement est normal et n’empêche pas l’utilisation de l’application avec VoiceOver.

Où trouver les informations de licence ?

Les informations de licence sont accessibles depuis le Centre d’aide, disponible dans le menu Aide.

Où consulter la fenêtre « À propos d’Apprenti Clavier » ?

La fenêtre « À propos d’Apprenti Clavier » est accessible depuis le menu Apprenti Clavier. Elle indique notamment la version installée de l’application.

Que se passe-t-il si je supprime un profil par erreur ?

La suppression d’un profil est définitive. Il est donc fortement recommandé d’effectuer une exportation avant toute suppression afin de conserver une sauvegarde pouvant être réimportée ultérieurement.

Pourquoi VoiceOver annonce-t-il parfois « Élément mis à jour » ?

VoiceOver peut annoncer « Élément mis à jour » lorsque l’application actualise une information affichée, par exemple après une saisie, un changement de progression ou l’ouverture d’un nouvel écran. Cette annonce indique simplement qu’un élément de l’interface a été modifié. Elle est normale, ne signale aucune erreur et n’empêche pas l’utilisation de l’application.

17. Conseils d’utilisation

Rythme conseillé

Une pratique régulière, même de courte durée, est préférable à des séances longues mais occasionnelles. La répétition favorise la mémorisation des gestes et améliore progressivement la vitesse ainsi que la précision. Ne cherchez pas à augmenter votre vitesse de frappe dès les premières leçons. Une frappe précise et régulière constitue la meilleure base pour progresser naturellement.

Position des mains

Prenez le temps de placer correctement vos mains sur le clavier avant de commencer une leçon. Une bonne position facilite l’apprentissage, limite les mouvements inutiles et contribue à développer progressivement les automatismes de frappe.

Utilisation avec VoiceOver

Si vous utilisez VoiceOver, prenez le temps d’écouter entièrement les annonces avant de poursuivre votre saisie. Lorsque l’option « Annoncer automatiquement le texte restant à taper » est activée, adaptez votre rythme afin de profiter pleinement des indications fournies par VoiceOver. Cette option peut être activée ou désactivée depuis les Réglages de l’application.

Utiliser plusieurs profils

Si plusieurs personnes utilisent le même Mac, il est recommandé que chaque apprenant dispose de son propre profil. Chacun bénéficie ainsi d’une progression et de statistiques indépendantes. Pour plus d’informations, consultez le chapitre « Gestion des profils apprenants ».

À savoir

Pensez à exporter régulièrement votre profil apprenant afin de conserver une sauvegarde récente de votre progression, notamment avant une mise à jour importante ou avant de supprimer ce profil.

Sur les anciennes versions de macOS

  • Sélectionnez Sécurité et confidentialité, puis l’onglet Général.
  • Dans la partie inférieure de la fenêtre, un message indique qu’Apprenti Clavier a été bloqué, car l’application ne provient pas d’un développeur identifié.

  • Rejoignez l’en-tête « Créer un formateur », puis utilisez VO + Flèche droite jusqu’au champ de saisie.
  • Saisissez votre nom, puis appuyez sur Entrée.
  • Dans la fenêtre « Créer un code PIN », le focus permet de commencer la saisie du code. Saisissez quatre chiffres, puis confirmez-les.

Saisir le code PIN

Le code PIN est visible par défaut. Utilisez le bouton « Masquer le code PIN » si vous ne souhaitez pas afficher les chiffres saisis. Le bouton devient ensuite « Afficher le code PIN ».

En cas d’erreur avant la fin de la saisie, la touche d’effacement permet de revenir au chiffre précédent. Si les deux codes saisis lors de la création ne correspondent pas, tous les champs sont effacés et le focus revient sur le premier chiffre.

Ouvrir un profil formateur existant

Dans la section « Choisissez un formateur », cliquez sur « Continuer avec [nom du formateur] ». Dans la fenêtre « Connexion de [nom du formateur] », saisissez votre code PIN. La connexion est automatique après le quatrième chiffre. Si le code est incorrect, les champs sont effacés afin de permettre une nouvelle saisie.

Avec VoiceOver

Rejoignez l’en-tête « Choisissez un formateur », puis utilisez VO + Flèche droite jusqu’au bouton « Continuer avec [nom du formateur] » correspondant au profil souhaité. Activez ce bouton avec VO + Espace. VoiceOver annonce ensuite le titre puis la description de la fenêtre de connexion, mais le focus est déjà placé dans le premier champ du code PIN. Vous pouvez donc commencer à saisir immédiatement votre code, sans attendre la fin de l’annonce et sans utiliser VO + Flèche droite.

Le bouton « Annuler » ou la touche Échap permet de revenir à l’accueil sans ouvrir le profil.

5. Les leçons personnalisées

Créer une leçon

Pour créer une leçon personnalisée, cliquez sur « Créer une leçon personnalisée » dans l’Espace formateur. L’éditeur de leçon s’ouvre.

Avec VoiceOver : dans l’Espace formateur, rejoignez le bouton « Créer une leçon personnalisée », puis activez-le avec VO + Espace.

Navigation dans l’éditeur

Les en-têtes sont présentés dans l’ordre suivant :

  • Créer une leçon personnalisée ou Modifier la leçon ;
  • Informations générales ;
  • Objectif pédagogique ;
  • Fiches pédagogiques, puis chaque fiche ;
  • Exercices, puis chaque exercice ;
  • Résumé de la leçon ;
  • Bénéficiaires de cette leçon.

Avec VoiceOver

  • À l’ouverture de l’éditeur, VoiceOver place le focus sur l’en-tête « Créer une leçon personnalisée ». Vous pouvez utiliser VO + Commande + H pour parcourir les en-têtes.
  • Dans certains champs de texte, VoiceOver peut parfois conserver le focus dans le champ. Dans ce cas, utilisez VO + Flèche droite pour en sortir et poursuivre la navigation dans l’éditeur.

Utilisation du rotor VoiceOver

Dans le rotor VoiceOver, sélectionnez « En-têtes Apprenti Clavier » pour parcourir les différents en-têtes de l’éditeur. Sélectionnez « Boutons Apprenti Clavier » pour parcourir directement les boutons disponibles.

Informations générales

Saisissez le titre de la leçon. Le sous-titre et l’introduction générale sont facultatifs. L’introduction sera annoncée avant les fiches pédagogiques et les exercices.

Objectif pédagogique

L’objectif pédagogique est facultatif. Cliquez sur le menu déroulant situé à droite de « Objectif pédagogique », puis choisissez l’objectif que vous souhaitez associer à la leçon.

Avec VoiceOver

  • Placez-vous sur le menu déroulant, annoncé par défaut « Aucun objectif sélectionné ».
  • Appuyez sur VO + Espace pour afficher le menu.
  • Placez-vous sur l’objectif souhaité. Si la navigation dans le menu est difficile, sélectionnez « Navigation » dans le rotor VoiceOver, puis parcourez les éléments du menu.
  • Appuyez sur Entrée pour confirmer votre sélection.

Fiches pédagogiques

Les fiches pédagogiques sont facultatives. Cochez la case « Je souhaite ajouter des fiches pédagogiques », puis choisissez leur nombre. Chaque fiche possède un titre et un contenu.

Le bouton « Ajouter une fiche pédagogique » ajoute une nouvelle fiche et place le focus VoiceOver sur son en-tête. Le bouton « Supprimer une ou plusieurs fiches pédagogiques » ouvre une fenêtre permettant de sélectionner les fiches à retirer.

Supprimer des fiches pédagogiques

Dans la fenêtre de suppression, cochez les fiches souhaitées dans la liste des éléments à sélectionner, puis cliquez sur « Supprimer la fiche sélectionnée » ou « Supprimer les fiches sélectionnées », selon leur nombre.

Avec VoiceOver

  • Placez-vous sur « Liste des éléments à sélectionner », puis utilisez VO + Majuscule + Flèche vers le bas pour entrer dans la zone de défilement.
  • Parcourez les fiches et cochez celles que vous souhaitez supprimer avec VO + Espace.
  • Utilisez VO + Majuscule + Flèche vers le haut pour sortir de la zone de défilement.
  • Utilisez VO + Fn + Flèche droite pour atteindre directement le bouton de suppression. Vous pouvez également vous déplacer plusieurs fois avec VO + Flèche droite.
  • Activez le bouton avec VO + Espace. Le focus revient ensuite sur l’en-tête « Fiches pédagogiques ».

Pour fermer cette fenêtre sans supprimer de fiche, utilisez le bouton « Annuler ».

Exercices

Une leçon doit comporter au moins un exercice. Pour chaque exercice, renseignez la consigne présentée à l’apprenant et le texte qu’il devra saisir.

Le bouton « Ajouter un exercice » ajoute un nouvel exercice et place le focus VoiceOver sur son en-tête. Le bouton « Supprimer un ou plusieurs exercices » ouvre une fenêtre de sélection.

Supprimer des exercices

La procédure est identique à celle utilisée pour les fiches pédagogiques : cochez les exercices à retirer dans la liste, puis cliquez sur le bouton de suppression. Le bouton « Annuler » permet de fermer la fenêtre sans supprimer d’élément.

Avec VoiceOver

  • Entrez dans « Liste des éléments à sélectionner » avec VO + Majuscule + Flèche vers le bas.
  • Cochez les exercices à supprimer avec VO + Espace, puis sortez de la zone avec VO + Majuscule + Flèche vers le haut.
  • Atteignez le bouton de suppression avec VO + Fn + Flèche droite ou avec plusieurs déplacements VO + Flèche droite, puis activez-le avec VO + Espace.

Après la suppression, le focus VoiceOver revient sur l’en-tête « Exercices ».

Résumé de la leçon

Le résumé final est facultatif. Cochez « Je souhaite ajouter un résumé final » pour afficher le champ correspondant.

Lorsqu’un objectif pédagogique est sélectionné, la case « Utiliser le résumé proposé selon l’objectif » permet d’insérer automatiquement un texte adapté. Vous pouvez décocher cette case et saisir votre propre résumé.

Bénéficiaires de cette leçon

Par défaut, la case « Tous les apprenants » est cochée. La leçon est alors accessible à tous les profils apprenants présents dans l’application.

Pour attribuer la leçon à certaines personnes seulement, décochez « Tous les apprenants », puis cochez chaque apprenant concerné.

Pour créer une leçon sans bénéficiaire, décochez la case « Tous les apprenants » et ne sélectionnez aucun apprenant. La leçon sera enregistrée, mais aucun apprenant ne pourra y accéder. Elle sera classée dans la section « Aucun bénéficiaire » de la fenêtre « Mes leçons personnalisées ».

Enregistrer ou annuler

Le bouton « Enregistrer la leçon » devient disponible lorsque la leçon possède un titre et au moins un exercice correctement renseigné. Cliquez sur ce bouton pour conserver la leçon. Le bouton « Annuler » revient à l’Espace formateur sans conserver les changements non enregistrés.

Avec VoiceOver : VO + Fn + Flèche droite atteint directement « Enregistrer la leçon ». Activez ensuite le bouton avec VO + Espace.

Maintenant que vous avez créé une leçon personnalisée, vous pouvez la prévisualiser, la modifier ou la supprimer.

Afficher mes leçons

Pour modifier ou prévisualiser une leçon, cliquez sur « Modifier ou prévisualiser mes leçons » dans l’Espace formateur. Vous pouvez également choisir « Afficher mes leçons » dans le menu « Formateur ».

Avec VoiceOver : dans l’Espace formateur, rejoignez le bouton « Modifier ou prévisualiser mes leçons », puis activez-le avec VO + Espace.

Les leçons sont regroupées par bénéficiaire dans l’ordre suivant :

  • Aucun bénéficiaire ;
  • Tous les bénéficiaires ;
  • le nom de chaque bénéficiaire, par ordre alphabétique.

Une catégorie apparaît uniquement lorsqu’elle contient au moins une leçon. Chaque catégorie est un en-tête et indique le nombre de leçons qu’elle contient.

Avec VoiceOver

Utilisez VO + Commande + H pour parcourir les catégories. Dans le rotor VoiceOver, « En-têtes Apprenti Clavier » permet également de sélectionner les en-têtes de cette fenêtre.

Après avoir atteint une catégorie, utilisez VO + Flèche droite pour parcourir ses leçons, puis VO + Espace pour afficher la fenêtre « Gestion de la leçon ».

Gestion de la leçon

Cette fenêtre présente le titre, l’objectif pédagogique lorsqu’il existe, le nombre de fiches, le nombre d’exercices et le nombre de bénéficiaires. Quatre boutons sont disponibles :

  • Prévisualiser la leçon ;
  • Modifier la leçon ;
  • Supprimer la leçon ;
  • Retour à mes leçons.

Prévisualiser la leçon

La prévisualisation permet de parcourir la leçon comme un apprenant, sans enregistrer de résultat dans ses statistiques. La touche Entrée permet de passer d’une fiche au prochain élément, de commencer les exercices et de terminer la leçon depuis le résumé.

Modifier la leçon

Le bouton « Modifier la leçon » permet de rouvrir l’éditeur afin de modifier le contenu ou les bénéficiaires de la leçon. L’éditeur s’ouvre avec les informations existantes. Après l’enregistrement, la leçon est classée dans la catégorie correspondant à ses bénéficiaires et VoiceOver revient sur son titre.

Supprimer la leçon

Le bouton « Supprimer la leçon » permet de supprimer définitivement la leçon sélectionnée. Une demande de confirmation présente les boutons « Annuler » et « Supprimer ». Après la suppression, la leçon disparaît de la liste. Une catégorie devenue vide n’est plus affichée.

Avec VoiceOver : la touche Échap ferme la fenêtre « Gestion de la leçon » et place de nouveau le focus sur la leçon précédemment sélectionnée.

Exporter mes leçons

Pour exporter vos leçons personnalisées, ouvrez le menu « Formateur », puis choisissez « Exporter mes leçons… ». Le fichier est enregistré dans le dossier Téléchargements et sélectionné dans le Finder.

Son nom respecte le modèle « Lecons-personnalisees-[nom du formateur]-Apprenti-Clavier.apprenticlavierlecons ». Si un fichier du même nom existe déjà, un numéro est ajouté, par exemple « -2 » ou « -3 », sans remplacer la sauvegarde précédente.

Importer des leçons

Pour importer des leçons personnalisées, ouvrez le menu « Formateur », puis choisissez « Importer des leçons… ». Sélectionnez ensuite un fichier portant l’extension `.apprenticlavierlecons`.

  • Une leçon absente de l’application est ajoutée.
  • Une leçon reconnue grâce à son identifiant est mise à jour uniquement si la version importée est plus récente.
  • Une leçon identique ou plus récente dans l’application est conservée sans modification.

La boîte de dialogue finale est intitulée « Importation réussie » ou « Leçons déjà présentes ». Elle indique le nombre de leçons ajoutées, mises à jour ou conservées, par exemple « 1 leçon mise à jour. ». Avec VoiceOver : appuyez sur Entrée pour la fermer.

Sauvegarde recommandée

Exportez régulièrement vos leçons, notamment avant de supprimer un profil formateur ou d’effectuer une modification importante.

6. Statistiques des apprenants

Pour accéder aux statistiques des apprenants, cliquez sur le bouton « Statistiques des apprenants » dans l’Espace formateur ou choisissez « Afficher les statistiques des apprenants » dans le menu « Formateur ».

Avec VoiceOver : dans l’Espace formateur, déplacez-vous jusqu’au bouton « Statistiques des apprenants », puis activez-le avec VO + Espace. À l’ouverture de la fenêtre, VoiceOver place le focus sur son titre.

Utilisation du rotor VoiceOver

Dans le rotor VoiceOver, sélectionnez « En-têtes Apprenti Clavier » pour parcourir les différents en-têtes de la fenêtre. Sélectionnez « Boutons Apprenti Clavier » pour parcourir directement les boutons disponibles.

Vue générale

Lorsque « Aucun apprenant sélectionné » est affiché dans le menu déroulant, la section « Informations générales » présente chaque apprenant sous forme d’en-tête avec :

  • le nombre de leçons terminées ;
  • le nombre d’erreurs ;
  • le nombre de tentatives enregistrées.

Choisir un apprenant

Cliquez sur le menu déroulant « Choisir un apprenant », puis sélectionnez la personne dont vous souhaitez consulter les résultats.

Avec VoiceOver

  • Placez-vous sur le menu déroulant et appuyez sur VO + Espace.
  • Choisissez l’apprenant, puis appuyez sur Entrée pour confirmer votre sélection.
  • Le focus se place sur l’en-tête « Statistiques de [nom de l’apprenant] ».

À noter : lorsque vous revenez à « Aucun apprenant sélectionné », le focus se place de nouveau sur l’en-tête « Informations générales ».

Statistiques détaillées

Pour l’apprenant sélectionné, la fenêtre présente le nombre de leçons terminées dans les 14 modules, les tentatives, les réussites, les erreurs et, lorsqu’elle est disponible, la vitesse moyenne en mots par minute.

Difficultés repérées

Les erreurs sont réparties dans les catégories suivantes :

  • Erreurs d’accent ;
  • Erreurs de ponctuation ;
  • Majuscules ou minuscules ;
  • Caractères manquants ;
  • Caractères en trop ;
  • Caractères incorrects.

Les résultats sont regroupés par module ou par leçons personnalisées du formateur. Pour chaque erreur détaillée, l’application peut présenter la leçon, le numéro de l’exercice, le texte attendu, le texte saisi et le type d’erreur.

Les statistiques enregistrées avec une ancienne version d’Apprenti Clavier peuvent ne pas contenir le détail du texte attendu ou du texte saisi.

Résultats des leçons personnalisées

Cette section présente les tentatives, les réussites et les erreurs enregistrées dans les leçons personnalisées effectuées par l’apprenant.

Exporter les statistiques

Pour exporter les statistiques, utilisez le bouton situé à droite du titre de la fenêtre. Lorsque aucun apprenant n’est sélectionné, il est intitulé « Exporter les statistiques de tous les apprenants ». Lorsqu’un apprenant est sélectionné, il devient « Exporter les statistiques de [nom de l’apprenant] ».

Le fichier texte est enregistré dans le dossier Téléchargements et sélectionné dans le Finder. Son nom est :

  • « Statistiques-de-tous-les-apprenants-Formateur-[nom du formateur]-Apprenti-Clavier.txt » pour l’ensemble des apprenants ;
  • « Statistiques-de-l-apprenant-[nom de l’apprenant]-Formateur-[nom du formateur]-Apprenti-Clavier.txt » pour un apprenant sélectionné.

Si un fichier existe déjà, un numéro est ajouté à son nom. Le message « Exportation réussie dans le dossier Téléchargements. » confirme l’opération.

Fermer la fenêtre

Vous pouvez fermer les statistiques avec le bouton « Fermer » situé en bas à droite, la touche Échap, Commande + W ou le bouton de fermeture standard de macOS situé en haut à gauche.

Avec VoiceOver : VO + Fn + Flèche droite atteint le dernier élément, « Fermer ». Activez-le avec VO + Espace. Après la fermeture, le focus revient sur l’en-tête « Espace formateur ».

7. Réglages

Navigation avec VoiceOver

À l’ouverture, VoiceOver place automatiquement le focus sur l’en-tête « Réglages ». Les catégories « Apparence », « Accessibilité VoiceOver », « Sons de validation des exercices », « Modification du code PIN » et « Suppression du profil de [nom du formateur] » sont également présentées comme des en-têtes. Vous pouvez donc naviguer par en-tête pour atteindre rapidement la catégorie souhaitée.

Utilisation du rotor VoiceOver

Dans le rotor VoiceOver, sélectionnez « En-têtes Réglages » pour parcourir directement les différentes catégories de la fenêtre.

Apparence

Choisissez l’apparence Automatique, Claire ou Sombre. Le mode Automatique suit le réglage d’apparence de macOS.

Annonce automatique du texte restant à taper

Lorsque cette option est activée, VoiceOver annonce automatiquement la partie du texte qu’il reste à saisir après chaque caractère tapé. Elle peut être activée ou désactivée à tout moment.

Délai des annonces VoiceOver

Ce réglage permet de choisir le temps d’attente avant l’annonce automatique du texte restant à taper. Cinq valeurs sont proposées :

  • Très rapide : un quart de seconde ;
  • Rapide : une demi-seconde ;
  • Normal : une seconde ;
  • Confortable : une seconde et demie ;
  • Lent : deux secondes.

Lorsque l’annonce automatique du texte restant à taper est désactivée, le réglage du délai devient indisponible, car il n’est alors plus nécessaire.

Sons de validation des exercices

La case « Sons de validation » permet d’activer ou de désactiver les sons joués pendant les exercices. Un son confirme une bonne réponse et un autre signale une réponse incorrecte. Cette option est cochée par défaut.

Modification du code PIN

Pour modifier le code PIN du profil formateur actif, cliquez sur « Modifier mon code PIN… ». La fenêtre « Modifier mon code PIN » s’ouvre.

Le formateur étant déjà connecté, l’ancien code PIN n’est pas demandé.

Choisir le nouveau code PIN

Dans la fenêtre « Modifier mon code PIN », saisissez directement un nouveau code à quatre chiffres, puis confirmez-le. La modification est automatique après le quatrième chiffre de confirmation.

Le code est visible par défaut. Utilisez « Masquer le code PIN » ou « Afficher le code PIN » selon votre besoin. La touche d’effacement permet de revenir au chiffre précédent. Si les deux saisies ne correspondent pas, tous les champs sont effacés afin de permettre une nouvelle saisie.

Le bouton « Annuler » ou la touche Échap ferme la fenêtre sans modifier le code. Lorsque l’opération réussit, le message « Code PIN modifié. » est affiché.

Supprimer le profil formateur actif

Dans « Suppression du profil de [nom du formateur] », cliquez sur « Supprimer ce profil… ». Une demande intitulée « Supprimer ce profil ? » indique : « Voulez-vous vraiment supprimer le profil formateur [nom] ? Le profil et ses leçons personnalisées seront définitivement effacés. »

Cliquez sur « Supprimer » pour confirmer ou sur « Annuler » pour conserver le profil. La suppression concerne uniquement ce formateur et ses leçons ; les autres profils ne sont pas supprimés.

Avant cette opération, il est recommandé d’exporter les leçons depuis le menu « Formateur ».

11. Raccourcis clavier utiles

Commandes générales

Ces commandes peuvent être utilisées avec ou sans VoiceOver :

  • Commande + Virgule : ouvre les Réglages.
  • Commande + W : ferme la fenêtre active lorsqu’elle prend en charge cette commande.
  • Commande + Q : quitte Apprenti Clavier.
  • Échap : revient à l’écran précédent ou ferme une fenêtre secondaire lorsqu’un retour est disponible.
  • Entrée : confirme une sélection ou permet de passer à l’élément suivant dans la prévisualisation d’une leçon.

Commandes VoiceOver

Dans les commandes suivantes, VO représente les touches Contrôle + Option :

  • VO + Flèche gauche ou VO + Flèche droite : parcourt les éléments de l’interface.
  • VO + Espace : active l’élément sélectionné.
  • VO + Commande + Flèche gauche ou VO + Commande + Flèche droite : parcourt les différents modes de navigation du rotor VoiceOver.
  • VO + Commande + H : atteint l’en-tête suivant.
  • VO + Commande + Majuscule + H : revient à l’en-tête précédent.
  • VO + Fn + Flèche gauche : atteint le premier élément de la zone parcourue.
  • VO + Fn + Flèche droite : atteint le dernier élément de la zone parcourue.
  • VO + M : place le curseur VoiceOver dans la barre des menus.
  • VO + K : ouvre l’Aide du clavier de VoiceOver.
  • VO + Majuscule + Flèche vers le bas : commence l’interaction avec une zone de défilement ou un groupe.
  • VO + Majuscule + Flèche vers le haut : arrête l’interaction avec la zone ou le groupe.

12. Questions fréquentes

Pourquoi le bouton « Enregistrer la leçon » est-il estompé ?

Le bouton devient disponible lorsque la leçon possède un titre et qu’au moins un exercice contient les informations nécessaires. Vérifiez notamment le contenu de l’exercice et le texte attendu. Les fiches pédagogiques, l’objectif et le résumé restent facultatifs.

Pourquoi un apprenant ne voit-il pas une leçon personnalisée ?

Vérifiez qu’il fait partie des bénéficiaires. Si « Tous les apprenants » a été décoché sans qu’aucun apprenant soit sélectionné, la leçon est classée dans la section « Aucun bénéficiaire » et reste inaccessible aux apprenants.

Puis-je modifier les bénéficiaires après la création ?

Oui. Ouvrez « Modifier ou prévisualiser mes leçons », sélectionnez la leçon, puis cliquez sur « Modifier la leçon ». Cochez ou décochez les bénéficiaires et enregistrez. La leçon est automatiquement classée dans la section correspondant à ses bénéficiaires.

Que se passe-t-il si j’importe une leçon déjà présente ?

Si l’application reconnaît son identifiant, la version importée remplace la leçon uniquement lorsqu’elle est plus récente. Une version identique ou une version locale plus récente est conservée. Une leçon inconnue est ajoutée.

Où sont enregistrés les fichiers exportés ?

Les leçons et les statistiques sont enregistrées dans le dossier Téléchargements. Le fichier est ensuite sélectionné dans le Finder. Si son nom existe déjà, un numéro comme « -2 » ou « -3 » est ajouté sans remplacer le fichier précédent.

Comment changer mon code PIN ?

Pour modifier votre code PIN, ouvrez la fenêtre « Réglages » depuis le menu « Apprenti Clavier » ou avec Commande + Virgule. Dans « Modification du code PIN », cliquez sur « Modifier mon code PIN… », puis saisissez le nouveau code et sa confirmation. L’ancien code n’est pas demandé puisque vous êtes déjà connecté.

La suppression d’un profil supprime-t-elle ses leçons ?

Oui. La suppression d’un profil formateur entraîne également la suppression définitive de toutes ses leçons personnalisées. Exportez-les au préalable depuis le menu « Formateur » afin de pouvoir les conserver et les importer ultérieurement.

13. Dépannage

VoiceOver ne se place pas sur l’élément attendu

Patientez quelques instants après l’ouverture d’une fenêtre afin de laisser VoiceOver annoncer son titre et placer le focus. Utilisez ensuite VO + Flèche gauche ou VO + Flèche droite. Vous pouvez aussi naviguer avec VO + Commande + H ou sélectionner le mode adapté dans le rotor VoiceOver.

La navigation reste positionnée dans un champ de texte

Selon la version de macOS, VoiceOver peut parfois rester positionné dans un champ. Utilisez VO + Flèche droite pour quitter ce champ et poursuivre la navigation.

Une fenêtre ne se ferme pas avec la touche Échap

Certaines fenêtres possèdent leur propre bouton « Annuler », « Fermer » ou « Retour ». Si Échap ne produit aucun effet, utilisez le bouton proposé. Dans les fenêtres compatibles, vous pouvez également essayer Commande + W.

Les sons de validation ne sont pas entendus

Vérifiez que la case « Sons de validation » est cochée dans les Réglages. Vérifiez également le volume du Mac et la sortie audio utilisée.

Les détails de certaines erreurs n’apparaissent pas

Les résultats enregistrés avec une ancienne version d’Apprenti Clavier peuvent ne pas contenir le texte attendu, le texte saisi ou la catégorie précise. Les nouvelles activités enregistreront ces informations lorsqu’elles sont disponibles.

Un fichier de leçons ne peut pas être importé

Vérifiez qu’il s’agit d’un fichier exporté par Apprenti Clavier portant l’extension `.apprenticlavierlecons`. Importez-le depuis « Importer des leçons… » dans le menu « Formateur ». Évitez de modifier manuellement son contenu ou son extension.

Le problème persiste

Quittez complètement Apprenti Clavier, puis relancez l’application. Si le problème persiste, choisissez « Signaler un problème… » dans le menu « Contact ».

Indiquez notamment :

  • la version d’Apprenti Clavier et celle de macOS ;
  • si VoiceOver était utilisé ;
  • la fenêtre concernée ;
  • les actions effectuées juste avant le problème ;
  • le message éventuellement affiché ou annoncé.

14. Conclusion

Apprenti Clavier a été conçu pour proposer un apprentissage progressif et accessible de la saisie au clavier.

Grâce au mode Formateur, vous pouvez créer des leçons personnalisées adaptées aux besoins de chaque apprenant, leur attribuer des bénéficiaires, les prévisualiser et les modifier à tout moment. Les statistiques vous permettent ensuite de suivre la progression des apprenants et de mieux identifier les difficultés qu’ils rencontrent.

Pensez à exporter régulièrement vos leçons personnalisées afin d’en conserver une copie. Vous pouvez également exporter les statistiques lorsque vous souhaitez les consulter ou les partager en dehors de l’application.

Si vous rencontrez un problème ou souhaitez proposer une amélioration, utilisez les options disponibles dans le menu « Contact ».

Nous vous souhaitons une excellente utilisation d’Apprenti Clavier et un accompagnement enrichissant auprès de vos apprenants.
